# Mac Setup

Everything needed to configure a Mac development environment — from first boot
through to a fully productive workspace. Includes discovery tools, package
management, shell configuration, and automated provisioning.

## What's in this brain

| File | What it covers |
|------|---------------|
| [who-am-i.md](./who-am-i.md) | Discover what's already installed on this Mac |
| [homebrew-essentials.md](./homebrew-essentials.md) | Package management, core tools, Brewfile |
| [shell-configuration.md](./shell-configuration.md) | zsh, oh-my-zsh, aliases, dotfiles |
| [dev-tools.md](./dev-tools.md) | Editors, languages, utilities |
| [ansible-automation.md](./ansible-automation.md) | Programmatic Mac provisioning with Ansible |
